💻 Esercizi — C++, programmazione procedurale

Dal flow chart al codice

Gli algoritmi visti come diagrammi di flusso nella sezione Flow Chart del percorso principale possono essere tradotti in C++ usando la programmazione procedurale: variabili semplici e funzioni che operano su di esse, senza classi.

In particolare, i blocchi di ripetizione del flow chart (while, do-while, for) diventano i cicli omonimi del linguaggio C++.

Il percorso qui sotto è a difficoltà crescente: parte dalla sintassi di base (input/output), passa per selezione e cicli, introduce le funzioni e chiude con gli array. Il blocco sulle funzioni precede volutamente quello sugli array: passare un array a una funzione richiede di aver già capito la differenza tra passaggio per valore e per riferimento. Prova a risolvere ogni esercizio da solo prima di rivelare la soluzione.

Esercizio 4 — Celsius in Fahrenheit

Consegna: chiedi una temperatura in gradi Celsius e convertila in Fahrenheit (formula: F = C × 9/5 + 32).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    double celsius;
    cin >> celsius;
    double fahrenheit = celsius * 9.0 / 5.0 + 32;
    cout << celsius << " C = " << fahrenheit << " F";
    return 0;
}

Attenzione a scrivere 9.0 / 5.0 e non 9 / 5: con interi la divisione darebbe 1 invece di 1.8.

2. Operatori ed espressioni (ancora senza if)

Esercizio 6 — Scambia due variabili

Consegna: scambia il contenuto di due variabili usando una terza variabile di appoggio. Bonus: prova a farlo senza variabile di appoggio.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    int temp = a;
    a = b;
    b = temp;

    cout << "a = " << a << ", b = " << b;
    return 0;
}

Bonus senza terza variabile: a = a + b; b = a - b; a = a - b; (funziona anche con lo XOR: a ^= b; b ^= a; a ^= b; ma solo con interi).

Esercizio 7 — Ore, minuti e secondi

Consegna: dato un numero di secondi, calcola a quante ore, minuti e secondi corrisponde (usa / e % tra interi).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int totale;
    cin >> totale;

    int ore = totale / 3600;
    int resto = totale % 3600;
    int minuti = resto / 60;
    int secondi = resto % 60;

    cout << ore << "h " << minuti << "m " << secondi << "s";
    return 0;
}

Esercizio 8 — Divisione tra interi

Consegna: calcola il resto della divisione tra due numeri e spiega perché 7 / 2 non fa 3.5 in C++.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 2;
    cout << a << " / " << b << " = " << (a / b) << endl;
    cout << a << " % " << b << " = " << (a % b) << endl;
    return 0;
}

Se entrambi gli operandi sono di tipo int, C++ esegue una divisione intera: il risultato è troncato (non arrotondato) alla parte intera, quindi 7 / 2 vale 3, non 3.5. Per ottenere il risultato decimale serve che almeno uno dei due operandi sia double, es. 7.0 / 2.

Esercizio 11 — Calcolatrice semplice (switch)

Consegna: leggi due numeri e un operatore (+, -, *, /), poi calcola e stampa il risultato usando uno switch.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;
    cin >> a >> op >> b;

    switch (op) {
        case '+':
            cout << a + b;
            break;
        case '-':
            cout << a - b;
            break;
        case '*':
            cout << a * b;
            break;
        case '/':
            if (b != 0) {
                cout << a / b;
            } else {
                cout << "Errore: divisione per zero";
            }
            break;
        default:
            cout << "Operatore non valido";
    }
    return 0;
}

Esercizio 18 — Numero primo

Consegna: stabilisci se un numero è primo, usando la strategia efficiente vista nella sezione Problemi del percorso principale (dividi solo fino alla metà del numero).

int main() {
    int n;
    cin >> n;

    bool primo = true;
    if (n < 2) {
        primo = false;
    }
    for (int i = 2; i <= n / 2 && primo; i++) {

            primo = false;
        }

    } else {
        cout << n << " non e' primo";
    }
    return 0;
}

Esercizio 20 — Menu ripetuto (do-while)

Consegna: realizza una piccola calcolatrice a menu che continua a chiedere l'operazione finché l'utente non sceglie "esci".

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int scelta;
    double a, b;

    do {
        cout << "1) Somma  2) Prodotto  0) Esci" << endl;
        cin >> scelta;

        if (scelta == 1) {
            cout << "Inserisci due numeri: ";
            cin >> a >> b;
            cout << "Risultato: " << (a + b) << endl;
        } else if (scelta == 2) {
            cout << "Inserisci due numeri: ";
            cin >> a >> b;
            cout << "Risultato: " << (a * b) << endl;
        }
    } while (scelta != 0);

    cout << "Arrivederci!";
    return 0;
}

Con il do-while il menu viene mostrato sempre almeno una volta, prima ancora di leggere la scelta dell'utente.

Esercizio 25 — Funzione ePrimo, riusata nel conteggio

Consegna: scrivi una funzione che verifica se un numero è primo e riusala per contare i numeri primi tra 1 e N (esercizio 23), evitando di duplicare il codice.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

bool ePrimo(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= n / 2; i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    int n;
    cin >> n;

    int conta = 0;
    for (int num = 2; num <= n; num++) {
        if (ePrimo(num)) {
            conta++;
        }
    }

    cout << "Numeri primi tra 1 e " << n << ": " << conta;
    return 0;
}

La stessa funzione ePrimo può essere richiamata anche per verificare un singolo numero, come nell'esercizio 18: ePrimo(n) restituisce direttamente true o false.

Esercizio 27 — Scambio per riferimento

Consegna: scrivi una funzione che scambia il valore di due variabili usando il passaggio per riferimento (&).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

void scambia(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x, y;
    cin >> x >> y;

    scambia(x, y);

    cout << "x = " << x << ", y = " << y;
    return 0;
}

Passando a e b per riferimento (&), la funzione modifica direttamente le variabili originali x e y. Se il parametro fosse passato per valore (senza &), lo scambio avverrebbe solo su una copia locale e non avrebbe alcun effetto fuori dalla funzione.

Esercizio 32 — Inverti un array

Consegna: inverti l'ordine degli elementi di un array, senza crearne uno nuovo (scambia gli elementi "in place").

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int v[10];
    for (int i = 0; i < 10; i++) {
        cin >> v[i];
    }

    for (int i = 0; i < 5; i++) {
        int temp = v[i];
        v[i] = v[9 - i];
        v[9 - i] = temp;
    }

    for (int i = 0; i < 10; i++) {
        cout << v[i] << " ";
    }
    return 0;
}

Basta scambiare a coppie il primo con l'ultimo, il secondo con il penultimo, e così via: per un array di 10 elementi servono solo 5 scambi (indici da 0 a 4).

Esercizio 34 — Ordinamento a bolle (bubble sort)

Consegna: ordina un array in ordine crescente usando l'algoritmo a bolle.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int v[10];
    for (int i = 0; i < 10; i++) {
        cin >> v[i];
    }

    for (int i = 0; i < 10 - 1; i++) {
        for (int j = 0; j < 10 - 1 - i; j++) {
            if (v[j] > v[j + 1]) {
                int temp = v[j];
                v[j] = v[j + 1];
                v[j + 1] = temp;
            }
        }
    }

    for (int i = 0; i < 10; i++) {
        cout << v[i] << " ";
    }
    return 0;
}

Ad ogni passaggio esterno, il ciclo interno confronta coppie di elementi adiacenti e li scambia se sono nell'ordine sbagliato: così, come una bolla, il valore più grande "sale" verso la fine dell'array.

Esercizio 35 — Rimuovi i duplicati

Consegna: rimuovi i valori duplicati da un array, mantenendo solo la prima occorrenza di ciascun valore (usa un array ausiliario o una logica in-place).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int v[10];
    for (int i = 0; i < 10; i++) {
        cin >> v[i];
    }

    int risultato[10];
    int n = 0;

    for (int i = 0; i < 10; i++) {
        bool giaPresente = false;
        for (int j = 0; j < n; j++) {
            if (risultato[j] == v[i]) {
                giaPresente = true;
            }
        }
        if (!giaPresente) {
            risultato[n] = v[i];
            n++;
        }
    }

    for (int i = 0; i < n; i++) {
        cout << risultato[i] << " ";
    }
    return 0;
}

L'array ausiliario risultato viene riempito solo con i valori non ancora incontrati; la variabile n tiene traccia di quanti elementi "unici" sono stati copiati finora.

8. Array e funzioni insieme (chiusura del percorso)

Esercizio 36 — Massimo/minimo, somma/media e conteggio pari come funzioni

Consegna: riscrivi gli esercizi 29, 30 e 31 come funzioni che ricevono l'array e la sua dimensione come parametri, così da poterle riusare con array di grandezza diversa.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int trovaMassimo(int v[], int dim) {
    int massimo = v[0];
    for (int i = 1; i < dim; i++) {
        if (v[i] > massimo) {
            massimo = v[i];
        }
    }
    return massimo;
}

int trovaMinimo(int v[], int dim) {
    int minimo = v[0];
    for (int i = 1; i < dim; i++) {
        if (v[i] < minimo) {
            minimo = v[i];
        }
    }
    return minimo;
}

double calcolaMedia(int v[], int dim) {
    int somma = 0;
    for (int i = 0; i < dim; i++) {
        somma = somma + v[i];
    }
    return (double) somma / dim;
}

int contaPari(int v[], int dim) {
    int conta = 0;
    for (int i = 0; i < dim; i++) {
        if (v[i] % 2 == 0) {
            conta++;
        }
    }
    return conta;
}

int main() {
    int v[10];
    for (int i = 0; i < 10; i++) {
        cin >> v[i];
    }

    cout << "Massimo: " << trovaMassimo(v, 10) << endl;
    cout << "Minimo: " << trovaMinimo(v, 10) << endl;
    cout << "Media: " << calcolaMedia(v, 10) << endl;
    cout << "Elementi pari: " << contaPari(v, 10) << endl;
    return 0;
}

In C++ un array passato a una funzione (int v[]) viaggia già "per riferimento": la funzione lavora direttamente sull'array originale, non su una copia. Per questo bisogna sempre passare anche la dimensione come parametro separato, dato che la funzione da sola non può conoscerla.
