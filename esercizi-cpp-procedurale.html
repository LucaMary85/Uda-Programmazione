💻 Esercizi — C++, programmazione procedurale

Dal flow chart al codice

Gli algoritmi visti come diagrammi di flusso nella sezione Flow Chart del percorso principale possono essere tradotti in C++ usando la programmazione procedurale: variabili semplici e funzioni che operano su di esse, senza classi.

In particolare, i blocchi di ripetizione del flow chart (while, do-while, for) diventano i cicli omonimi del linguaggio C++.

Il percorso qui sotto è a difficoltà crescente e segue lo stesso ordine della sezione di teoria C++: sintassi di base, operatori, selezione, cicli, funzioni, puntatori, array, vector, stringhe, casting e infine struct — l'ultimo passo prima della programmazione a oggetti. Il blocco sulle funzioni precede volutamente quello sui puntatori e sugli array: passare un dato a una funzione per modificarlo davvero richiede di aver già capito la differenza tra passaggio per valore e per riferimento. Prova a risolvere ogni esercizio da solo prima di rivelare la soluzione.

Come leggere le etichette degli esercizi

  • 📽️ Da proiettare — introduce una sintassi mai vista o un'insidia classica della teoria: conviene spiegarlo e risolverlo insieme alla classe, prima di lasciare spazio all'esercitazione autonoma.
  • ✏️ Autonomo — riusa un pattern già mostrato in un esercizio "da proiettare" della stessa sezione, cambiando solo il problema: adatto come esercitazione individuale o compito, con la soluzione da rivelare solo dopo il tentativo.

Esercizio 4 — Celsius in Fahrenheit ✏️ Autonomo

Consegna: chiedi una temperatura in gradi Celsius e convertila in Fahrenheit (formula: F = C × 9/5 + 32).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    double celsius;
    cin >> celsius;
    double fahrenheit = celsius * 9.0 / 5.0 + 32;
    cout << celsius << " C = " << fahrenheit << " F";
    return 0;
}

Attenzione a scrivere 9.0 / 5.0 e non 9 / 5: con interi la divisione darebbe 1 invece di 1.8.

2. Operatori ed espressioni (ancora senza if)

Esercizio 6 — Scambia due variabili 📽️ Da proiettare

Consegna: scambia il contenuto di due variabili usando una terza variabile di appoggio. Bonus: prova a farlo senza variabile di appoggio.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    int temp = a;
    a = b;
    b = temp;

    cout << "a = " << a << ", b = " << b;
    return 0;
}

Bonus senza terza variabile: a = a + b; b = a - b; a = a - b; (funziona anche con lo XOR: a ^= b; b ^= a; a ^= b; ma solo con interi).

Esercizio 7 — Ore, minuti e secondi ✏️ Autonomo

Consegna: dato un numero di secondi, calcola a quante ore, minuti e secondi corrisponde (usa / e % tra interi).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int totale;
    cin >> totale;

    int ore = totale / 3600;
    int resto = totale % 3600;
    int minuti = resto / 60;
    int secondi = resto % 60;

    cout << ore << "h " << minuti << "m " << secondi << "s";
    return 0;

Esercizio 8 — Divisione tra interi ✏️ Autonomo

Consegna: calcola il resto della divisione tra due numeri e spiega perché 7 / 2 non fa 3.5 in C++.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 2;
    cout << a << " / " << b << " = " << (a / b) << endl;
    cout << a << " % " << b << " = " << (a % b) << endl;
    return 0;
}

Se entrambi gli operandi sono di tipo int, C++ esegue una divisione intera: il risultato è troncato (non arrotondato) alla parte intera, quindi 7 / 2 vale 3, non 3.5. Per ottenere il risultato decimale serve che almeno uno dei due operandi sia double, es. 7.0 / 2.

Esercizio 9 — Area e circonferenza con una costante 📽️ Da proiettare

Consegna: chiedi il raggio di un cerchio e calcola area e circonferenza, usando una costante PI dichiarata con const (formule: area = π·r², circonferenza = 2·π·r).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.14159; // non deve mai cambiare: dichiararla const lo garantisce
    double raggio;
    cin >> raggio;

    double area = PI * raggio * raggio;
    double circonferenza = 2 * PI * raggio;

    cout << "Area: " << area << endl;
    cout << "Circonferenza: " << circonferenza << endl;

    // PI = 3.0; // se scommentata: ERRORE DI COMPILAZIONE, non si puo' riassegnare una costante
    return 0;
}

Usare const non è solo una convenzione stilistica: se per errore in mezzo al codice si scrivesse PI = 3.0;, il compilatore lo segnalerebbe subito come errore, invece di lasciare che un bug del genere passi inosservato fino all'esecuzione.

Esercizio 10 — Pre-incremento e post-incremento 📽️ Da proiettare

Consegna: parti da due variabili uguali e mostra la differenza tra ++a (pre-incremento) e b++ (post-incremento) quando il risultato viene usato subito in un'assegnazione.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = 5;

    int risultatoPre = ++a;  // PRE: a diventa 6 PRIMA di essere letto -> risultatoPre vale 6
    int risultatoPost = b++; // POST: risultatoPost prende il valore ATTUALE (5) -> POI b diventa 6

    cout << "a = " << a << ", risultatoPre = " << risultatoPre << endl;   // a = 6, risultatoPre = 6
    cout << "b = " << b << ", risultatoPost = " << risultatoPost << endl; // b = 6, risultatoPost = 5
    return 0;
}

Alla fine a e b valgono entrambe 6: l'incremento avviene comunque. Cambia solo quale valore viene "fotografato" nella variabile di destinazione: quello già aggiornato (pre) o quello di un istante prima (post).

Esercizio 12 — Pari o dispari con l'operatore ternario 📽️ Da proiettare

Consegna: riscrivi l'esercizio precedente usando l'operatore ternario condizione ? valoreSeVero : valoreSeFalso al posto dell'if/else completo.

Mostra soluzione in C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    // equivalente compatto dell'if/else dell'esercizio 11
    string esito = (n % 2 == 0) ? "pari" : "dispari";

    cout << n << " e' " << esito;
    return 0;
}

Il ternario conviene quando si deve solo scegliere un valore da assegnare o stampare, come qui. Per una logica più complessa (più di due strade, più istruzioni per ramo, oppure un cin dentro una delle due alternative) serve invece un vero if/else, come quello visto negli esercizi successivi.

Esercizio 14 — Calcolatrice semplice (switch) 📽️ Da proiettare

Consegna: leggi due numeri e un operatore (+, -, *, /), poi calcola e stampa il risultato usando uno switch.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;
    cin >> a >> op >> b;

    switch (op) {
        case '+':
            cout << a + b;
            break;
        case '-':
            cout << a - b;
            break;
        case '*':
            cout << a * b;
            break;
        case '/':
            if (b != 0) {
                cout << a / b;
            } else {
                cout << "Errore: divisione per zero";
            }
            break;
        default:
            cout << "Operatore non valido";
    }
    return 0;
}

Esercizio 16 — Anno bisestile ✏️ Autonomo

Esercizio 21 — Numero primo ✏️ Autonomo

Consegna: stabilisci se un numero è primo, usando la strategia efficiente vista nella sezione Problemi del percorso principale (dividi solo fino alla metà del numero).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    bool primo = true;
    if (n < 2) {
        primo = false;
    }
    for (int i = 2; i <= n / 2 && primo; i++) {
        if (n % i == 0) {
            primo = false;
        }
    }

    if (primo) {
        cout << n << " e' primo";
    } else {
        cout << n << " non e' primo";
    }
    return 0;
}

Esercizio 22 — Sequenza di Fibonacci 📽️ Da proiettare

Consegna: stampa i primi N termini della sequenza di Fibonacci (0, 1, 1, 2, 3, 5, 8, ...).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        cout << a << " ";
        int successivo = a + b;
        a = b;
        b = successivo;
    }

}

Esercizio 23 — Somma con valore sentinella (while) 📽️ Da proiettare

Consegna: leggi numeri interi e sommali finché l'utente non inserisce 0 (che non va sommato), poi stampa il totale.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int n, somma = 0;
    cin >> n;

    while (n != 0) {
        somma = somma + n;
        cin >> n;
    }

    cout << "Somma: " << somma;
    return 0;
}

A differenza del for, qui non sappiamo in anticipo quante volte si ripeterà il ciclo: si continua finché la condizione resta vera. Notate la lettura "di apertura" prima del while e quella "di chiusura" alla fine del corpo: se il primo numero inserito è già 0, il ciclo non parte nemmeno una volta, a differenza del do-while che vedremo tra poco.

Esercizio 24 — Conta le cifre di un numero (while) ✏️ Autonomo

Consegna: leggi un numero intero positivo e conta quante cifre ha, dividendolo ripetutamente per 10.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int cifre = 0;
    while (n != 0) {
        cifre = cifre + 1;
        n = n / 10;
    }

    cout << "Numero di cifre: " << cifre;
    return 0;
}

Qui il while non serve a leggere input ripetutamente, ma a ridurre n un pezzo alla volta finché non arriva a zero: un caso classico in cui, non conoscendo a priori il numero di cifre, un for non si potrebbe scrivere altrettanto naturalmente.

Esercizio 25 — Raddoppia finché non superi un limite (while) ✏️ Autonomo

Consegna: leggi un numero e un limite, poi stampa il numero e i suoi raddoppi successivi finché restano minori o uguali al limite.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int n, limite;
    cin >> n >> limite;

    while (n <= limite) {
        cout << n << " ";
        n = n * 2;
    }

    return 0;
}

Se n è già maggiore del limite, il corpo del ciclo non viene eseguito nemmeno una volta e non viene stampato nulla: è la stessa caratteristica "controllo in testa" vista nell'esercizio 23.

Esercizio 26 — Menu ripetuto (do-while) 📽️ Da proiettare

Consegna: realizza una piccola calcolatrice a menu che continua a chiedere l'operazione finché l'utente non sceglie "esci".

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int scelta;
    double a, b;

    do {
        cout << "1) Somma  2) Prodotto  0) Esci" << endl;
        cin >> scelta;

        if (scelta == 1) {
            cout << "Inserisci due numeri: ";
            cin >> a >> b;
            cout << "Risultato: " << (a + b) << endl;
        } else if (scelta == 2) {
            cout << "Inserisci due numeri: ";
            cin >> a >> b;
            cout << "Risultato: " << (a * b) << endl;
        }
    } while (scelta != 0);

    cout << "Arrivederci!";
    return 0;
}

Con il do-while il menu viene mostrato sempre almeno una volta, prima ancora di leggere la scelta dell'utente.

Esercizio 29 — Quanti primi tra 1 e N ✏️ Autonomo

Esercizio 31 — Funzione ePrimo, riusata nel conteggio ✏️ Autonomo

Consegna: scrivi una funzione che verifica se un numero è primo e riusala per contare i numeri primi tra 1 e N (esercizio 29), evitando di duplicare il codice.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

bool ePrimo(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= n / 2; i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    int n;
    cin >> n;

    int conta = 0;
    for (int num = 2; num <= n; num++) {
        if (ePrimo(num)) {
            conta++;
        }
    }

    cout << "Numeri primi tra 1 e " << n << ": " << conta;
    return 0;
}

La stessa funzione ePrimo può essere richiamata anche per verificare un singolo numero, come nell'esercizio 21: ePrimo(n) restituisce direttamente true o false.

Esercizio 33 — Scambio per riferimento 📽️ Da proiettare

Consegna: scrivi una funzione che scambia il valore di due variabili usando il passaggio per riferimento (&).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

void scambia(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x, y;
    cin >> x >> y;

    scambia(x, y);

    cout << "x = " << x << ", y = " << y;
    return 0;
}

Passando a e b per riferimento (&), la funzione modifica direttamente le variabili originali x e y. Se il parametro fosse passato per valore (senza &), lo scambio avverrebbe solo su una copia locale e non avrebbe alcun effetto fuori dalla funzione. Nel prossimo blocco vedremo come ottenere lo stesso risultato con i puntatori, la tecnica "sotto al cofano" di cui i riferimenti sono una scorciatoia.

7. Puntatori

Esercizio 34 — Primo contatto con i puntatori 📽️ Da proiettare

Consegna: dichiara una variabile intera e un puntatore ad essa; stampa il valore della variabile, il suo indirizzo di memoria e il valore letto tramite il puntatore; infine modifica la variabile attraverso il puntatore.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int numero = 42;
    int *ptr = nullptr; // dichiarazione: il puntatore non punta ancora a nulla

    ptr = &numero; // & = "indirizzo di": ptr ora punta a numero

    cout << "Valore di numero: " << numero << endl;
    cout << "Indirizzo di numero: " << &numero << endl;
    cout << "Contenuto di ptr (indirizzo): " << ptr << endl;
    cout << "Valore puntato da ptr (*ptr): " << *ptr << endl;

    *ptr = 100; // scrivo ATTRAVERSO il puntatore: modifico davvero "numero"
    cout << "Nuovo valore di numero: " << numero << endl; // 100
    return 0;
}

L'indirizzo stampato (&numero e ptr) sarà lo stesso: ptr non contiene un numero "a caso", ma proprio la posizione in memoria di numero. Per questo scrivere in *ptr equivale a scrivere direttamente in numero.

Esercizio 35 — Raddoppia con un puntatore (confronto con il riferimento) 📽️ Da proiettare

Consegna: scrivi due funzioni che raddoppiano un intero: una che riceve un puntatore (int*) e una che riceve un riferimento (int&, come nell'esercizio 33). Confronta come si chiamano e come si scrivono.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

void raddoppiaConPuntatore(int *n) {
    *n = *n * 2; // devo dereferenziare esplicitamente con * per leggere/scrivere il valore
}

void raddoppiaConRiferimento(int &n) {
    n = n * 2; // il riferimento nasconde la dereferenziazione: si usa "n" come una variabile normale
}

int main() {
    int x = 10;
    raddoppiaConPuntatore(&x); // alla chiamata devo passare esplicitamente l'indirizzo con &
    cout << "Dopo raddoppiaConPuntatore: " << x << endl; // 20

    int y = 10;
    raddoppiaConRiferimento(y); // alla chiamata basta passare "y": niente & ne' *
    cout << "Dopo raddoppiaConRiferimento: " << y << endl; // 20
    return 0;
}

Le due funzioni ottengono esattamente lo stesso risultato: modificano davvero la variabile del chiamante, non una copia. Cambia solo la sintassi: con il puntatore l'indirizzo (&x) e la dereferenziazione (*n) sono scritti a mano dal programmatore; con il riferimento li gestisce il compilatore "dietro le quinte". In C++ moderno si preferisce il riferimento quando è possibile, ma è importante conoscere anche i puntatori: molte librerie e codice più datato li usano ancora, e sono indispensabili in casi che il riferimento non copre (es. un puntatore che può valere nullptr, o che deve poter cambiare a quale variabile punta).

Esercizio 42 — Ordinamento a bolle (bubble sort) 📽️ Da proiettare

Consegna: ordina un array in ordine crescente usando l'algoritmo a bolle.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int v[10];
    for (int i = 0; i < 10; i++) {
        cin >> v[i];
    }

    for (int i = 0; i < 10 - 1; i++) {
        for (int j = 0; j < 10 - 1 - i; j++) {
            if (v[j] > v[j + 1]) {
                int temp = v[j];
                v[j] = v[j + 1];
                v[j + 1] = temp;
            }
        }
    }

    for (int i = 0; i < 10; i++) {
        cout << v[i] << " ";
    }
    return 0;
}

Ad ogni passaggio esterno, il ciclo interno confronta coppie di elementi adiacenti e li scambia se sono nell'ordine sbagliato: così, come una bolla, il valore più grande "sale" verso la fine dell'array.

Esercizio 43 — Rimuovi i duplicati ✏️ Autonomo

Consegna: rimuovi i valori duplicati da un array, mantenendo solo la prima occorrenza di ciascun valore (usa un array ausiliario o una logica in-place).

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int main() {
    int v[10];
    for (int i = 0; i < 10; i++) {
        cin >> v[i];
    }

    int risultato[10];
    int n = 0;

    for (int i = 0; i < 10; i++) {
        bool giaPresente = false;
        for (int j = 0; j < n; j++) {
            if (risultato[j] == v[i]) {
                giaPresente = true;
            }
        }
        if (!giaPresente) {
            risultato[n] = v[i];
            n++;
        }
    }

    for (int i = 0; i < n; i++) {
        cout << risultato[i] << " ";
    }
    return 0;
}

L'array ausiliario risultato viene riempito solo con i valori non ancora incontrati; la variabile n tiene traccia di quanti elementi "unici" sono stati copiati finora.

9. Array e funzioni insieme (chiusura del percorso sugli array)

Esercizio 44 — Massimo/minimo, somma/media e conteggio pari come funzioni 📽️ Da proiettare

Consegna: riscrivi gli esercizi 34, 35 e 36 come funzioni che ricevono l'array e la sua dimensione come parametri, così da poterle riusare con array di grandezza diversa.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

int trovaMassimo(int v[], int dim) {
    int massimo = v[0];
    for (int i = 1; i < dim; i++) {
        if (v[i] > massimo) {
            massimo = v[i];
        }
    }
    return massimo;
}

int trovaMinimo(int v[], int dim) {
    int minimo = v[0];
    for (int i = 1; i < dim; i++) {
        if (v[i] < minimo) {
            minimo = v[i];
        }
    }
    return minimo;
}

double calcolaMedia(int v[], int dim) {
    int somma = 0;
    for (int i = 0; i < dim; i++) {
        somma = somma + v[i];
    }
    return (double) somma / dim;
}

int contaPari(int v[], int dim) {
    int conta = 0;
    for (int i = 0; i < dim; i++) {
        if (v[i] % 2 == 0) {
            conta++;
        }
    }
    return conta;
}

int main() {
    int v[10];
    for (int i = 0; i < 10; i++) {
        cin >> v[i];
    }

    cout << "Massimo: " << trovaMassimo(v, 10) << endl;
    cout << "Minimo: " << trovaMinimo(v, 10) << endl;
    cout << "Media: " << calcolaMedia(v, 10) << endl;
    cout << "Elementi pari: " << contaPari(v, 10) << endl;
    return 0;
}

In C++ un array passato a una funzione (int v[]) viaggia già "per riferimento": la funzione lavora direttamente sull'array originale, non su una copia. Per questo bisogna sempre passare anche la dimensione come parametro separato, dato che la funzione da sola non può conoscerla.

10. Vector (array a dimensione dinamica)

Esercizio 45 — Numeri letti finché l'utente non si ferma 📽️ Da proiettare

Consegna: leggi numeri da input finché l'utente non digita 0, memorizzandoli in un vector<int> (senza sapere in anticipo quanti saranno), poi stampali tutti insieme al loro conteggio.

Mostra soluzione in C++ 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numeri; // parte vuoto: a differenza di un array, non serve dichiarare una dimensione
    int valore;

    cout << "Inserisci numeri (0 per terminare): " << endl;
    cin >> valore;
    while (valore != 0) {
        numeri.push_back(valore); // aggiunge in fondo: il vector cresce da solo
        cin >> valore;
    }

    cout << "Hai inserito " << numeri.size() << " numeri: ";
    for (int i = 0; i < numeri.size(); i++) {
        cout << numeri[i] << " ";
    }
    return 0;
}

Con un array questo esercizio sarebbe scomodo: bisognerebbe dichiarare in anticipo una dimensione "abbastanza grande" e tenere un contatore a parte per sapere quanti elementi sono stati davvero usati. Il vector risolve il problema alla radice: cresce esattamente di quanto serve, ed espone size() per sapere sempre quanti elementi contiene davvero.

Esercizio 46 — Filtra i numeri pari in un nuovo vector ✏️ Autonomo

Consegna: dato un vector<int> già popolato, crea un secondo vector vuoto e riempilo solo con gli elementi pari del primo.

Mostra soluzione in C++ 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> numeri = {3, 8, 15, 22, 7, 10, 1};

Questo pattern — "vector vuoto + push_back dentro un ciclo" — è uno degli usi più comuni del vector: costruire una nuova collezione, di dimensione non nota a priori, filtrando o trasformando una collezione di partenza.

Esercizio 48 — Parola palindroma ✏️ Autonomo

Consegna: dì se una parola si legge allo stesso modo da sinistra a destra e da destra a sinistra (es. "otto", "anna").

#include <iostream>
#include <string>
using namespace std;

int main() {
    string parola;
    cin >> parola;

    bool palindroma = true;
    int fine = parola.length() - 1;

Esercizio 49 — Trova e sostituisci una parola 📽️ Da proiettare

Consegna: in un testo, trova la prima occorrenza di una parola data e sostituiscila con un'altra, usando find e substr (senza librerie apposite per la sostituzione).

Mostra soluzione in C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string testo = "Il gatto insegue il topo nel giardino";
    string daCercare = "topo";
    string sostituto = "TOPO";

    int posizione = testo.find(daCercare); // indice del carattere dove inizia "topo"

    if (posizione != string::npos) { // npos = valore speciale che significa "non trovata"
        string prima = testo.substr(0, posizione);                       // tutto cio' che precede
        string dopo = testo.substr(posizione + daCercare.length());      // tutto cio' che segue

    } else {
        cout << "Parola non trovata" << endl;
    }
    return 0;
}

string::npos è il valore speciale restituito da find quando la sottostringa cercata non esiste: va sempre controllato prima di usare il risultato di find, altrimenti si rischia di "tagliare" la stringa in un punto sbagliato.

12. Conversioni di tipo (casting)

Esercizio 50 — Da stringa a numero e viceversa 📽️ Da proiettare

Consegna: converti una stringa numerica in int con stoi, tronca un double con static_cast<int> e converti un codice numerico in un carattere con static_cast<char> (codifica ASCII).

Mostra soluzione in C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string input = "27";
    int eta = stoi(input); // "string to int": converte il testo "27" nell'intero 27

    double mediaVoti = 7.8;

}

Scrivere static_cast<...>(...) invece di affidarsi a una conversione implicita (come int x = mediaVoti;) rende esplicita e visibile l'intenzione del programmatore: chi legge il codice capisce subito che il troncamento è voluto, non un errore dimenticato.

#include <iostream>

struct Persona {

Esercizio 52 — Array di struct: la media della classe ✏️ Autonomo

Consegna: definisci una struct Studente (nome, voto), crea un array di 3 studenti leggendone i dati da input, calcola la media dei voti e stampa i nomi degli studenti sopra la media.

Mostra soluzione in C++ 
#include <iostream>
#include <string>
using namespace std;

struct Studente {
    string nome;
    double voto;
};

int main() {
    const int NUM_STUDENTI = 3;
    Studente classe[NUM_STUDENTI]; // un array di struct: ogni elemento e' uno Studente completo

    for (int i = 0; i < NUM_STUDENTI; i++) {
        cout << "Nome dello studente " << (i + 1) << ": ";
        cin >> classe[i].nome;
        cout << "Voto: ";
        cin >> classe[i].voto;
    }

    double somma = 0;
    for (int i = 0; i < NUM_STUDENTI; i++) {
        somma = somma + classe[i].voto; // accedo al campo voto di ogni struct nell'array
    }
    double media = somma / NUM_STUDENTI;

    cout << "Media della classe: " << media << endl;

    for (int i = 0; i < NUM_STUDENTI; i++) {
        if (classe[i].voto > media) {
            cout << classe[i].nome << " e' sopra la media" << endl;
        }
    }
    return 0;
}

Ogni elemento di classe[] non è un singolo numero come negli array visti finora, ma un intero Studente con i suoi campi: per questo si accede prima all'elemento con [i] e poi al campo con ., come in classe[i].voto.

Esercizio 53 — Una struct come parametro di funzione 📽️ Da proiettare

Consegna: definisci una struct Rettangolo (base, altezza); scrivi una funzione area che la riceve per valore e una funzione raddoppiaBase che la riceve per riferimento, e osserva la differenza.

Mostra soluzione in C++ 
#include <iostream>
using namespace std;

struct Rettangolo {
    double base;
    double altezza;
};

double area(Rettangolo r) { // "r" e' una COPIA: modificarla qui non cambierebbe l'originale
    return r.base * r.altezza;
}

void raddoppiaBase(Rettangolo &r) { // per riferimento: modifica DAVVERO l'originale
    r.base = r.base * 2;
}

int main() {
    Rettangolo rett = {4.0, 3.0};

    cout << "Area iniziale: " << area(rett) << endl;

    raddoppiaBase(rett);
    cout << "Base dopo raddoppio: " << rett.base << endl;
    cout << "Area dopo raddoppio: " << area(rett) << endl;
    return 0;
}

Una struct, come qualunque altra variabile, viaggia per valore di default: area(rett) lavora su una copia di rett, quindi non lo modifica mai. Solo il simbolo & nel parametro di raddoppiaBase permette alla funzione di toccare l'oggetto originale — esattamente la stessa regola già vista con le variabili semplici (esercizio 33) e con i puntatori (esercizio 35).
